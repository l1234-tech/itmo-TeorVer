# Случайные события и пространство элементарных исходов

## 1. Случайный эксперимент

Случайный эксперимент — опыт, результат которого заранее нельзя точно определить при заданных условиях. Теория вероятностей описывает закономерности таких экспериментов, особенно при многократном повторении.

**Примеры:** бросок кубика, подбрасывание монеты, случайный выбор человека из группы.

## 2. Пространство элементарных исходов

Пространство элементарных исходов обозначают (Omega). Это множество всех возможных взаимоисключающих и неделимых исходов эксперимента. Один элемент (omega\in\Omega) называется элементарным исходом.

Пример: при броске стандартного кубика
\[
\Omega=\{1,2,3,4,5,6\}.
\]
В одном броске реализуется ровно один из этих исходов.

Пространство исходов должно быть:
- **полным** — учитывать все результаты, которые возможны в принятой модели;
- **согласованным** — элементарные исходы не должны происходить одновременно;
- достаточно подробным для ответа на поставленный вопрос.

Одно явление можно описывать разными пространствами в зависимости от задачи. Например, при броске кубика можно различать все шесть граней или только два результата: «выпало чётное» и «выпало нечётное».

## 3. Событие

Событие (A) — подмножество пространства исходов: (A\subseteq\Omega). Оно происходит, если реализовавшийся исход принадлежит (A).

Для кубика событие «выпало чётное число»:
\[
A=\{2,4,6\}.
\]

### Виды событий

- **Элементарное событие** содержит один исход, например ({4}).
- **Сложное событие** содержит несколько исходов, например ({2,4,6}).
- **Достоверное событие** — всё пространство (Omega); оно происходит всегда.
- **Невозможное событие** — пустое множество (arnothing); оно не происходит.
- **Противоположное событие** (overline A) содержит исходы, в которых (A) не произошло.

Если (Omega) содержит (n) исходов, то у него (2^n) подмножеств. Поэтому число всех событий в конечной модели равно (2^n), если событием считается любое подмножество пространства.

## 4. Пример: две монеты

Пусть О — орёл, Р — решка, а монеты различаются по порядку (первая, вторая). Тогда
\[
\Omega=\{ОО,ОР,РО,РР\}.
\]

Событие «на первой монете выпал орёл»:
\[
A=\{ОО,ОР\}.
\]
Событие «выпали одинаковые стороны»:
\[
B=\{ОО,РР\}.
\]
Событие «выпал хотя бы один орёл»:
\[
C=\{ОО,ОР,РО\}.
\]

В этой модели (A) и (B) пересекаются: исход (ОО) принадлежит обоим событиям. Если монеты симметричны и броски независимы, четыре элементарных исхода равновероятны, но равновероятность требует отдельного обоснования и не следует только из записи множества.

## 5. Связь событий с вероятностью

В классической модели с конечным числом равновозможных исходов вероятность события равна отношению числа благоприятных исходов к общему числу исходов:
\[
P(A)=\frac{|A|}{|\Omega|}.
\]
Эта формула не универсальна: она требует конечности и равновозможности исходов. В более общей аксиоматической модели вероятность задаётся вероятностной мерой.

## Краткое резюме

1. (Omega) перечисляет все элементарные исходы принятой модели.
2. Событие — множество исходов, при которых оно происходит.
3. (Omega) — достоверное событие, (arnothing) — невозможное.
4. Сначала формализуй эксперимент и событие, затем выбирай способ вычисления вероятности.
