# Задачи: случайные события

Для каждой задачи сначала запиши пространство элементарных исходов и только затем определи нужные события.

1. Бросают стандартный шестигранный кубик. Запиши $\Omega$, событие $A$: выпало число больше 4, и событие $B$: выпало нечётное число.
2. Бросают две различимые монеты. Запиши пространство исходов и событие «выпал ровно один орёл».
3. Для эксперимента из задачи 2 запиши события «на первой монете орёл» и «выпали одинаковые стороны». Найди их пересечение.
4. В эксперименте из задачи 1 опиши достоверное и невозможное события примерами подмножеств $\Omega$.
5. Пространство состоит из 5 элементарных исходов. Сколько всего событий существует, если любое подмножество считается событием?
6. Два раза бросают кубик и записывают упорядоченную пару результатов. Сколько элементарных исходов в пространстве $\Omega$? Опиши событие «сумма результатов равна 7».
7. Для $\Omega=\{1,2,3,4,5,6\}$ задай событие $A=\{2,4,6\}$. Найди противоположное событие $overline A$.
