## Структура темы

Каждая тема оформляется единообразно:
- `README.md` — определения, объяснения, формулы, свойства и разобранные примеры;
- `tasks.md` — задачи, сгруппированные по сложности;
- `solutions.md` — пошаговые решения всех задач из раздела;
- `examples.py` — программные примеры, если код помогает понять тему.

## Правила работы с материалами

1. Сохранять математический смысл исходных лекций и корректно обозначать условия применения формул.
2. Для каждой задачи приводить последовательное решение: анализ условия, выбор метода, подстановка, вычисления и ответ.
3. Дополнять пробелы стандартной теорией, сохраняя логичный порядок курса.
4. Проверять ссылки, формулы и вычисления перед публикацией.
